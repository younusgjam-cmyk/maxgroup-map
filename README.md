# MaxGroup Map 🗺️

تطبيق ويب حديث لعرض وإدارة المواقع والفروع باستخدام React.

## الميزات ✨

- 📍 عرض قائمة بالفروع والمواقع
- 🗺️ واجهة تفاعلية لعرض معلومات الموقع
- 📱 تصميم responsive يدعم جميع الأجهزة
- 🌐 دعم اللغة العربية مع RTL
- 🎨 تصميم عصري وجذاب

## التثبيت 🚀

### متطلبات النظام
- Node.js 14.0 أو أحدث
- npm أو yarn

### خطوات التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/younusgjam-cmyk/maxgroup-map.git
cd maxgroup-map
```

2. تثبيت الحزم:
```bash
npm install
```

3. تشغيل التطبيق:
```bash
npm start
```

سيفتح التطبيق تلقائياً على `http://localhost:3000`

## البناء 🏗️

لإنشاء نسخة إنتاجية:
```bash
npm run build
```

## الاستخدام 📖

1. **عرض الفروع**: اضغط على أي موقع في القائمة الجانبية
2. **عرض المعلومات**: سيتم عرض تفاصيل الموقع والإحداثيات الجغرافية
3. **التوافقية**: يعمل بسلاسة على الهواتف والأجهزة اللوحية وأجهزة سطح المكتب
